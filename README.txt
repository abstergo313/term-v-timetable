ABHISHEK TERM V TIMETABLE

Static responsive timetable website.

Included:
- 100 classes from the supplied Term V schedule
- B2B Gr 2, BS-PPP Gr 1, GTM Gr 2, PRS Gr 1, MDPW Gr 1
- Fixed IST display (no browser timezone shifting)
- Next-class countdown
- Week navigation + agenda view
- Course filters
- Term progress and class counts
- Mobile responsive + installable PWA
- Day footnotes for quiz/guest lecture windows, MAD Project, Placement and Sangram
- Offline cache after first load
